Pure-Go ChaCha20-Poly1305 (RFC 8439), copied unchanged except for import paths and
build tags from the copy of golang.org/x/crypto that ships inside the Go source tree
(src/vendor/golang.org/x/crypto, Go 1.24.7). Only the generic implementations are kept,
so the provider stays free of external modules and builds the same on every platform.
