Providers

Connect your machine

Enter your machine code (it stays the same until you change it with innernet-provider rekey; see it any time with innernet-provider code). Then add a passkey so you can manage this machine from any device. If this device already has one for this machine, you just confirm it.

Do not have a code? On the machine, run innernet-provider start. The code keeps working while that terminal stays open.

This machine already has a passkey? Sign in with it instead: no code needed while innernet-provider start is waiting.
