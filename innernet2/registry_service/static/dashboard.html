Lost this machine or its key?

You have a key backup: on the new or reinstalled machine run innernet-provider restore FILE, then innernet-provider start. It comes back as this same machine, with its listing, earnings history and passkeys.

No backup: the key cannot be recovered (nobody has a copy, not even us). Retire this machine below: clients move their files away, the machine code stops working and the payout contract becomes free. Then install again on any machine (curl -fsSL https://innernetcorp.com/install.sh | sh) and use the same payout contract.
