The passphrase was right: this backup belongs to machine .

To get the machine back (on the same or a new computer):

  1. Download the backup file below and copy it to that computer.
  2. Install without starting setup: curl -fsSL https://innernetcorp.com/install.sh | INNERNET_NO_START=1 sh
  3. If this computer already has an INNERNET key, move it away first: mv ~/.innernet/provider/identity.key ~/identity.key.old
  4. Restore: innernet-provider restore innernet-backup.json (asks this passphrase), then innernet-provider start.

Anyone with this key can act as your machine. Do not paste it into chats, emails or websites.

No backup, or the passphrase is gone

Then the key cannot be recovered. Retire the machine on your dashboard ("Lost this machine or its key?"): clients move their files away and the payout contract becomes free. Install again on any computer, add it to your account, and use the same payout contract.
